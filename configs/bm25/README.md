# BM25 配置文件说明

## 📁 配置文件组织

### **基础配置**
- **`basic.yml`** - 最基础的BM25配置，使用标准参数

### **参数调优配置**
- **`tuned_k1_high.yml`** - 高k1值配置 (k1=2.0)
- **`tuned_k1_low.yml`** - 低k1值配置 (k1=0.8)
- **`tuned_b_high.yml`** - 高b值配置 (b=0.9)
- **`tuned_b_low.yml`** - 低b值配置 (b=0.5)

### **论文数量限制配置**
- **`limited_papers_5.yml`** - 限制5篇最近论文
- **`limited_papers_10.yml`** - 限制10篇最近论文
- **`random_papers_5.yml`** - 随机选择5篇论文

### **Embedding增强配置**
- **`embedding_scincl_5.yml`** - SciNCL embedding选择5篇论文
- **`embedding_scincl_10.yml`** - SciNCL embedding选择10篇论文

### **预计算优化配置**
- **`precomputed_basic.yml`** - 使用预计算BM25索引
- **`precomputed_embedding.yml`** - 使用预计算BM25索引和embedding

## 🔧 BM25参数详解

### **核心BM25参数**

#### **bm25_k1** (词频饱和参数)
- **默认值**: 1.2
- **范围**: 0.5-3.0
- **作用**: 控制词频对相关性分数的影响程度
- **调优指导**:
  - **高值 (1.5-3.0)**: 适合长文档，高频词影响更大
  - **低值 (0.5-1.0)**: 适合短文档，词频影响更平缓
  - **标准值 (1.2)**: 大多数场景的最佳选择

#### **bm25_b** (长度归一化参数)
- **默认值**: 0.75
- **范围**: 0.0-1.0
- **作用**: 控制文档长度对相关性分数的影响程度
- **调优指导**:
  - **高值 (0.8-1.0)**: 强化长度归一化，适合长度差异大的文档集
  - **低值 (0.3-0.6)**: 减弱长度归一化，允许长文档保持优势
  - **标准值 (0.75)**: 平衡长短文档的影响

### **审稿人画像参数**

#### **max_papers_per_reviewer**
- **默认值**: null (不限制)
- **作用**: 限制每个审稿人用于构建画像的论文数量
- **影响**: 
  - **限制数量**: 减少噪声，提高效率，但可能丢失信息
  - **不限制**: 保留完整信息，但可能引入噪声

#### **paper_selection_method**
- **选项**: "all", "recent", "random", "embedding_based"
- **作用**: 选择审稿人论文的策略
- **比较**:
  - **all**: 使用所有论文，信息最完整
  - **recent**: 使用最近论文，反映当前兴趣
  - **random**: 随机选择，避免时间偏差
  - **embedding_based**: 智能选择，质量最高但计算成本高

#### **embedding_model_name**
- **默认值**: null
- **作用**: 用于embedding_based选择的模型
- **推荐**: "models/sentence-transformers/scincl" (科学文献专用)

### **缓存优化参数**

#### **use_precomputed**
- **默认值**: false
- **作用**: 是否使用预计算的BM25索引
- **优势**: 显著减少在线时间（99%+加速）
- **要求**: 需要先运行offline_preprocessing.py

#### **cache_dir**
- **默认值**: "cache"
- **作用**: 预计算缓存的存储目录

## 🚀 使用建议

### **实验设计建议**
1. **基线实验**: 使用 `basic.yml`
2. **参数调优**: 使用 `tuned_*` 系列配置
3. **效率优化**: 使用 `limited_papers_*` 配置
4. **质量提升**: 使用 `embedding_*` 配置
5. **生产部署**: 使用 `precomputed_*` 配置

### **数据集适配建议**
- **小数据集** (NIPS, SIGIR): 使用基础配置
- **中等数据集** (KDD, SciRepEval): 考虑论文数量限制
- **大数据集** (exHarmony): 必须使用预计算优化

### **性能对比预期**
- **basic**: 基线性能，计算时间中等
- **tuned_***: 性能可能有小幅提升
- **limited_papers_***: 计算时间减少，性能可能略降
- **embedding_***: 性能显著提升，计算时间增加
- **precomputed_***: 计算时间大幅减少，性能保持
